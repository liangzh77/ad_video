# 技术研究：视频物料整理工具

**日期**: 2025-12-11
**分支**: `001-video-material-organizer`

## 研究概述

本文档记录技术选型的研究结论，所有决策均遵循项目宪法的"简单优先"原则。

---

## 1. GUI 框架选择

### 决策
使用 **PySide6**

### 理由
- Qt 官方维护的 Python 绑定，稳定可靠
- 文档完善，中文资料丰富
- 内置视频/音频播放支持（QMediaPlayer）
- 内置文件树组件（QTreeView）
- LGPL 许可，可用于个人项目

### 考虑的替代方案

| 方案 | 优点 | 排除原因 |
|------|------|----------|
| PyQt6 | 功能相同 | GPL 许可限制 |
| tkinter | Python 内置 | 界面简陋，媒体播放支持差 |
| wxPython | 跨平台 | 文档较少，API 不如 Qt 直观 |
| Electron | 现代 UI | 过重，需要前端技术栈 |

---

## 2. 视频处理库选择

### 决策
使用 **moviepy** + **Pillow**

### 理由
- moviepy 是 Python 最简单的视频处理库
- 提取帧和音频只需几行代码
- Pillow 处理图片格式转换
- 无需了解 ffmpeg 命令行

### 核心用法示例

```python
from moviepy.editor import VideoFileClip

# 提取第一帧
clip = VideoFileClip("video.mp4")
clip.save_frame("frame.jpg", t=0)

# 提取音频
clip.audio.write_audiofile("audio.mp3")
```

### 考虑的替代方案

| 方案 | 优点 | 排除原因 |
|------|------|----------|
| ffmpeg-python | 功能强大 | 需要理解 ffmpeg 参数 |
| opencv | 图像处理强 | 音频处理不便 |
| PyAV | 底层控制 | API 复杂 |

## 3. 配置存储方案

### 决策
使用 **JSON 文件**

### 理由
- Python 标准库内置支持
- 人类可读，便于调试
- 符合"简单优先"原则
- 无需额外依赖

### 配置文件位置
- Windows: `%APPDATA%\VideoMaterialOrganizer\config.json`
- 或与应用同目录: `./config.json`

### 配置内容
```json
{
  "data_directory": "D:/视频物料",
  "default_prompts": {
    "subtitle": "请根据以下字幕内容...",
    "image": "请根据这张图片..."
  }
}
```

## 4. 文件命名与目录结构

### 决策
采用规格说明中定义的命名规则

### 目录结构
```text
[数据目录]/
├── [模板名1]/
│   ├── 模板，视频，[模板名1].mp4
│   ├── 模板，头帧，[模板名1].jpg
│   ├── 模板，声音，[模板名1].mp3
│   ├── 模板，字幕，[模板名1].srt
│   ├── 01/                          # 生成视频子文件夹
│   │   ├── 01，字幕.srt
│   │   ├── 01，语音，[主语音名].mp3
│   │   ├── 01，头帧.jpg
│   │   ├── 01，可灵.mp4
│   │   └── 01，成片.mp4
│   └── 02/
│       └── ...
└── [模板名2]/
    └── ...
```

### 编号规则
- 使用两位数字编号：01, 02, 03...
- 新建时自动查找下一个可用编号

## 5. 媒体播放方案

### 决策
使用 **PySide6 内置的 QMediaPlayer**

### 理由
- 无需额外依赖
- 支持常见视频/音频格式
- 与 Qt 界面无缝集成

### 备选方案（如遇兼容性问题）
- python-vlc：VLC 的 Python 绑定，格式支持更广

---

## 6. 字幕编辑方案

### 决策
使用 **QPlainTextEdit** 组件

### 理由
- 简单的纯文本编辑
- SRT 格式本质是文本文件
- 无需复杂的字幕解析

### SRT 格式示例
```text
1
00:00:00,000 --> 00:00:02,000
第一句字幕

2
00:00:02,500 --> 00:00:05,000
第二句字幕
```
