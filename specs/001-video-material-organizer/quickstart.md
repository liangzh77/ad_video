# 快速开始：视频物料整理工具

## 环境要求

- Python 3.11+
- Windows 操作系统

## 安装

```bash
# 克隆仓库
git clone <repository-url>
cd ad_video

# 创建虚拟环境（推荐）
python -m venv venv
venv\Scripts\activate

# 安装依赖
pip install PySide6 moviepy Pillow
```

## 运行

```bash
python src/main.py
```

## 首次使用

1. **设置数据目录**: 启动应用后，选择一个文件夹作为数据存储目录
2. **创建模板**: 点击"新建模板"，输入模板名称
3. **添加模板视频**: 选择视频文件，点击"设为模板视频"
4. **提取素材**: 点击"提取头帧"和"提取音频"
5. **创建生成项目**: 点击"新建生成视频"，开始制作流程

## 文件结构示例

设置数据目录为 `D:\视频物料` 后：

```text
D:\视频物料\
├── 模板A\
│   ├── 模板，视频，模板A.mp4
│   ├── 模板，头帧，模板A.jpg
│   ├── 模板，声音，模板A.mp3
│   ├── 模板，字幕，模板A.srt
│   └── 01\
│       ├── 01，字幕.srt
│       └── 01，成片.mp4
└── 模板B\
    └── ...
```

## 常用操作

| 操作 | 说明 |
|------|------|
| 新建模板 | 创建一个空的模板文件夹 |
| 设为模板视频 | 将选中的视频复制为模板视频 |
| 提取头帧 | 从模板视频中提取第一帧 |
| 提取音频 | 从模板视频中提取音频 |
| 新建生成视频 | 在模板下创建一个新的生成项目 |
| 复制 Prompt | 将 Prompt 复制到剪贴板 |

## 故障排除

### 视频无法播放
- 确保安装了系统解码器
- 尝试将视频转换为 MP4 (H.264) 格式

### 提取头帧失败
- 确保视频文件未损坏
- 检查 moviepy 是否正确安装

### 界面显示异常
- 确保 PySide6 正确安装
- 尝试重新安装：`pip install --force-reinstall PySide6`
