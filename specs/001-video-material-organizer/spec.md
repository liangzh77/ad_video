## 用户场景与测试 *(必填)*

### 用户故事 1 - 模板管理与文件准备 (优先级: P1)

作为视频制作者，我希望能够创建模板文件夹，并通过多种方式准备模板所需的文件（视频、头帧、音频、字幕），所有文件都是可选的，可以自动提取也可以手动传入。

**优先级理由**: 模板管理是整个工作流程的起点，灵活的文件准备方式能适应不同的工作场景。

**独立测试**: 可通过创建模板并以不同方式添加文件，验证系统是否正确处理各种输入方式。

**验收场景**:

1. **Given** 用户输入模板名称，**When** 用户点击"新建模板"，**Then** 系统创建以模板名命名的空文件夹
2. **Given** 模板文件夹已创建，**When** 用户选择一个视频文件并点击"设为模板视频"，**Then** 系统将视频复制到模板文件夹并重命名为"模板，视频，【模板名】.mp4"
3. **Given** 模板已有视频文件，**When** 用户点击"提取头帧"，**Then** 系统从视频中提取第一帧并保存为"模板，头帧，【模板名】.jpg"
4. **Given** 用户选择一个图片文件，**When** 用户点击"设为头帧"，**Then** 系统将图片复制到模板文件夹并重命名为"模板，头帧，【模板名】.jpg"
5. **Given** 模板已有视频文件，**When** 用户点击"提取音频"，**Then** 系统从视频中提取音频并保存为"模板，声音，【模板名】.mp3"
6. **Given** 用户选择一个音频文件，**When** 用户点击"设为音频"，**Then** 系统将音频复制到模板文件夹并重命名为"模板，声音，【模板名】.mp3"
7. **Given** 用户选择一个字幕文件，**When** 用户点击"设为字幕"，**Then** 系统将字幕复制到模板文件夹并重命名为"模板，字幕，【模板名】.srt"
8. **Given** 模板字幕位置为空，**When** 用户在文本框中输入字幕内容并点击"保存字幕"，**Then** 系统将内容保存为"模板，字幕，【模板名】.srt"

### 用户故事 2 - 文件浏览与预览 (优先级: P2)

作为视频制作者，我希望在界面左侧看到所有模板和生成视频的文件列表，点击任意文件可以查看详情、播放视频/音频或显示文本内容，以便快速定位和预览物料。

**优先级理由**: 文件浏览是日常使用中最频繁的操作，良好的预览功能能大幅提升工作效率。

**独立测试**: 可通过在左侧列表点击不同类型的文件，验证是否能正确显示预览内容。

**验收场景**:

1. **Given** 系统已有模板文件夹，**When** 用户打开应用，**Then** 左侧显示所有模板文件夹的列表
2. **Given** 模板文件夹存在但某些预设文件缺失，**When** 用户查看该模板，**Then** 缺失的文件位置显示为"未设置"状态
3. **Given** 左侧显示文件列表，**When** 用户点击一个视频文件，**Then** 右侧显示视频播放器并可以播放该视频
4. **Given** 左侧显示文件列表，**When** 用户点击一个音频文件，**Then** 右侧显示音频播放器并可以播放该音频
5. **Given** 左侧显示文件列表，**When** 用户点击一个文本/字幕文件，**Then** 右侧显示该文件的文本内容（可编辑）

---

### 用户故事 3 - 生成视频流程管理 (优先级: P3)

作为视频制作者，我希望为每个模板创建多个"生成视频"子项目，每个子项目有清晰的流程步骤提示，并为每个步骤的输出文件预留位置，以便有条理地完成视频生成工作。

**优先级理由**: 生成视频是最终目标，流程管理帮助用户追踪进度、避免遗漏步骤。

**独立测试**: 可通过创建一个新的生成视频项目，验证流程步骤是否正确显示，文件位置是否正确预留。

**验收场景**:

1. **Given** 用户已有一个模板，**When** 用户点击"新建生成视频"，**Then** 系统在该模板文件夹下创建一个编号子文件夹
2. **Given** 生成视频子文件夹已创建，**When** 用户查看该子文件夹，**Then** 左侧列表显示完整的生成流程步骤（固定步骤列表），每个步骤标注状态（待处理/已完成）
3. **Given** 某个流程步骤对应的文件已存在，**When** 系统检测到该文件，**Then** 该步骤状态自动更新为"已完成"
4. **Given** 某个流程步骤需要文件，**When** 用户传入对应文件，**Then** 系统将文件复制到正确位置并更新状态
5. **Given** 用户想要修改某步骤的文件，**When** 用户重新传入文件，**Then** 系统覆盖原有文件
6. **Given** 用户想要删除某步骤的文件，**When** 用户点击删除，**Then** 系统删除该文件并将步骤状态更新为"待处理"

**流程步骤定义**（固定，顺序自由）:
1. 字幕生成：用大模型根据模板字幕生成新字幕，输出"编号，字幕.srt"
2. 语音生成：在剪映中处理后导出语音，输出"编号，语音，【主语音名】.mp3"
3. 头帧生成：用大模型根据模板头帧生成新头帧，输出"编号，头帧.jpg"
4. 可灵视频：用语音和头帧生成视频，输出"编号，可灵.mp4"
5. 成片导出：在剪映中完成最终编辑，输出"编号，成片.mp4"

### 用户故事 4 - 大模型 Prompt 管理 (优先级: P4)

作为视频制作者，我希望在需要使用大模型的步骤中，系统显示默认的 Prompt 模板，我可以修改、一键复制、并保存为新的默认值，以便快速准备大模型输入。

**优先级理由**: Prompt 管理是提升效率的辅助功能，帮助用户快速完成需要大模型参与的步骤。

**独立测试**: 可通过查看大模型相关步骤，验证 Prompt 显示、编辑、复制和保存功能是否正常。

**验收场景**:

1. **Given** 用户查看"用大模型生成新字幕"步骤，**When** 系统显示该步骤，**Then** 显示默认的字幕生成 Prompt 模板
2. **Given** Prompt 模板已显示，**When** 用户修改 Prompt 内容并点击"复制"，**Then** 修改后的 Prompt 被复制到剪贴板
3. **Given** Prompt 模板已修改，**When** 用户点击"保存为默认"，**Then** 该 Prompt 成为此步骤的新默认模板

---

### 边界情况

- 模板文件夹可以完全为空（无视频、无头帧、无音频、无字幕）
- 用户尝试从不存在的视频提取头帧/音频时，系统显示"请先设置模板视频"提示
- 用户传入的文件格式不支持时，系统显示明确的错误提示
- 用户尝试创建重名的模板时，系统提示并建议使用不同名称
- 生成视频子文件夹编号冲突时，系统自动使用下一个可用编号
- 文件路径包含特殊字符时，系统正确处理或提示用户修改
- 字幕文本框内容为空时保存，系统提示确认是否创建空字幕文件
- 用户可以按任意顺序完成流程步骤，不强制顺序执行

## 需求 *(必填)*

### 功能需求

**文件与目录管理**:
- **FR-001**: 系统必须支持用户指定一个根数据目录，所有模板和生成视频文件夹存放于此
- **FR-002**: 系统必须支持创建空的模板文件夹，命名为用户指定的模板名称
- **FR-003**: 系统必须在模板文件夹内创建生成视频子文件夹，使用递增编号命名
- **FR-004**: 系统必须按照规定的命名规则复制和保存文件

**模板文件管理（所有文件均为可选）**:
- **FR-005**: 系统必须支持用户传入视频文件作为模板视频（复制到指定位置）
- **FR-006**: 系统必须支持从模板视频中提取第一帧作为头帧图片（JPG 格式）
- **FR-007**: 系统必须支持用户直接传入头帧图片（复制到指定位置）
- **FR-008**: 系统必须支持从模板视频中提取音频轨道（MP3 格式）
- **FR-009**: 系统必须支持用户直接传入音频文件（复制到指定位置）
- **FR-010**: 系统必须支持用户传入字幕文件（复制到指定位置）
- **FR-011**: 系统必须支持用户在文本框中编辑并保存字幕内容

**文件预览**:
- **FR-012**: 系统必须在左侧面板显示文件树结构，包含预设文件位置
- **FR-013**: 系统必须对缺失的预设文件显示"未设置"状态
- **FR-014**: 系统必须支持视频文件的播放预览
- **FR-015**: 系统必须支持音频文件的播放预览
- **FR-016**: 系统必须支持文本/字幕文件的内容显示和编辑

**流程管理**:
- **FR-017**: 系统必须为生成视频显示固定的流程步骤列表（5个步骤：字幕、语音、头帧、可灵视频、成片）
- **FR-018**: 系统必须标注每个流程步骤的完成状态
- **FR-019**: 系统必须检测步骤对应文件是否存在，并自动更新状态
- **FR-020**: 系统必须支持用户为流程步骤传入、覆盖或删除文件
- **FR-021**: 系统必须允许用户按任意顺序完成流程步骤

**Prompt 管理**:
- **FR-022**: 系统必须为大模型相关步骤显示默认 Prompt
- **FR-023**: 系统必须支持 Prompt 的编辑和一键复制
- **FR-024**: 系统必须支持将修改后的 Prompt 保存为新的默认值

**配置与设置**:
- **FR-025**: 系统必须将用户设置保存在本地配置文件中
- **FR-026**: 系统必须能够记住上次打开的数据目录

### 关键实体

- **模板 (Template)**: 代表一个模板及其相关文件集合，包含模板名称、可选的视频、头帧、音频、字幕（所有文件均可缺失）
- **生成项目 (GeneratedProject)**: 代表一次视频生成任务，包含编号、流程状态、各步骤输出文件
- **流程步骤 (WorkflowStep)**: 代表生成视频流程中的一个固定步骤，包含步骤名称、描述、预期输出文件、完成状态、关联的 Prompt（如有）；步骤列表固定但执行顺序自由
- **Prompt 模板 (PromptTemplate)**: 代表大模型使用的提示词模板，包含步骤类型、默认内容、用户自定义内容

## 成功标准 *(必填)*

### 可衡量结果

- **SC-001**: 用户能够在 2 分钟内完成一个新模板的创建和文件设置
- **SC-002**: 用户能够在 3 次点击内定位并预览任意物料文件
- **SC-003**: 用户能够通过流程列表清晰了解每个生成视频的完成进度
- **SC-004**: 用户能够在 10 秒内完成 Prompt 的复制操作
- **SC-005**: 应用能够正常管理 50 个以上模板及其生成视频而不影响基本使用体验
- **SC-006**: 所有操作均有明确的中文界面提示和反馈

## 假设

- 用户使用 Windows 操作系统
- 用户的视频文件为常见格式（MP4、AVI、MOV 等）
- 用户有基本的文件管理经验
- 大模型操作（如生成字幕、生成头帧）在外部平台完成，应用仅管理 Prompt 和输出文件
- 所有模板文件都是可选的，用户可以根据需要选择性地准备
